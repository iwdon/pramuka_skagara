PRAMUKA SKAGARA - VERSI PHP
=============================

Folder tujuan:
C:\laragon\www\pramuka_skagara\

Salin file:
- index.php
- profil.php
- prestasi.php
- berita.php
- jadwal-latihan.php
- dokumentasi.php
- materi.php
- pendaftaran.php
- kontak.php

Pastikan:
1. config/database.php sudah ada.
2. Database pramuka_skagara sudah di-import.
3. Apache dan MySQL Laragon berjalan.

URL:
http://localhost/pramuka_skagara/

Catatan:
- Desain HTML/CSS/JS dari file yang Anda kirim dipertahankan.
- pendaftaran.php sudah disiapkan untuk INSERT ke tabel pendaftaran.
- kontak.php sudah disiapkan untuk INSERT ke tabel kontak.
- Halaman konten lainnya sudah menjadi PHP dan siap tahap berikutnya untuk mengganti data statis menjadi query MySQL.
